# AI Messenger + Admin Mode

Простий вебсайт у форматі месенджера:
- користувач пише повідомлення у чаті;
- AI відповідає автоматично;
- адміністратор може увімкнути ручний режим і відповідати людям замість AI.

## Файли
- `index.html` — сторінка користувача.
- `admin.html` — адмін-панель.
- `styles.css` — стилі.
- `app.js` — логіка користувацького чату.
- `admin.js` — логіка адмін-панелі.

## Запуск
Оскільки це статичний сайт, можна відкрити `index.html` напряму або підняти простий сервер:

```bash
python3 -m http.server 8080
```

Після цього відкрийте:
- `http://localhost:8080/index.html` — чат;
- `http://localhost:8080/admin.html` — адмінка.

## Як працює
Стан зберігається у `localStorage` (`ai_messenger_state_v1`), тому чат і адмінка синхронізуються між вкладками одного браузера.
