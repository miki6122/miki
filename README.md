# AI Messenger + Hidden Admin Control Room

Оновлений вебсайт у форматі месенджера:
- користувач реєструється по імені та спілкується з AI;
- AI відповідає у більш «людському» стилі;
- адмін-панель прихована, має секретний вхід, реєстрацію адміна та пароль;
- в адмінці є вкладки для кращої навігації: Inbox / Діалог / Налаштування.

## Файли
- `index.html` — сторінка користувача.
- `admin.html` — прихована адмін-панель (Control Room).
- `styles.css` — стилі.
- `app.js` — логіка користувацького чату, реєстрація користувача, секретний вхід в адмінку.
- `admin.js` — логіка адмін-панелі, авторизація, вкладки навігації.

## Запуск локально
```bash
python3 -m http.server 8080
```

Після цього відкрийте:
- `http://localhost:8080/index.html` — чат користувача.

## Як потрапити в адмінку
Адмін-панель максимально прихована:
- натисніть комбінацію `Alt + Shift + A` на сторінці чату;
- введіть секретний код: `shadow-entry-2049`;
- після цього відкриється `admin.html`.

> Примітка: у прототипі це клієнтський захист (frontend-only), тому для production треба робити серверну авторизацію.

## Перший вхід адміна
При першому відкритті `admin.html`:
- створюється адмін-акаунт (логін + пароль);
- далі потрібен вхід по цих даних.

## Публікація (швидко через GitHub Pages)
1. Запуште репозиторій на GitHub.
2. Відкрийте `Settings -> Pages`.
3. Увімкніть `Deploy from a branch`, виберіть гілку `main` і папку `/root`.
4. Отримайте посилання виду: `https://<username>.github.io/<repo>/index.html`.

## Як працює
Стан зберігається у `localStorage`:
- чатові повідомлення/режими: `ai_messenger_state_v2`;
- користувач: `ai_messenger_user_v1`;
- адмін: `ai_messenger_admin_user_v1` + сесія.

Для сумісності з попередньою версією застосунку автоматично читається старий ключ `ai_messenger_state_v1`, якщо новий ще не створено.
